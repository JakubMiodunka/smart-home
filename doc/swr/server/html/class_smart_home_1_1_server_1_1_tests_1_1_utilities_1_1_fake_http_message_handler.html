CancellationToken cancellationToken )
protected

This method acts as a mediator in the request data exchange. Here it allows us to intercept requests sent by the HttpClient during test case execution.

We must create a RequestSnapshot here because the original HttpRequestMessage is disposed of automatically further down the pipeline. Capturing a snapshot ensures that the request data (especially the Content stream) remains available for assertions even after the request cycle is complete, preventing ObjectDisposedException.
