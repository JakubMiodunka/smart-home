Initializes a new instance of the RequireRemoteIpAddressAttribute class.

This constructor is intended for normal application use. The logger is resolved from HttpContext.RequestServices during action execution.

Filters applied directly as attributes cannot receive constructor dependencies through dependency injection. Using constructor injection would require registering the attribute as a service and applying it ex. via [ServiceFilter], which adds unnecessary complexity.

◆ OnActionExecuting()

override void SmartHome.Server.Api.Controllers.RequireRemoteIpAddressAttribute.OnActionExecuting ( ActionExecutingContext context)

Extracts the remote IP address before executing the action in the controller.

The extracted IP address is stored in HttpContext.Items under the key RemoteIpAddressKey. If the remote IP address cannot be determined, the request is rejected with an HTTP 400 Bad Request response.

Parameters
contextContext of action executed in controller.
