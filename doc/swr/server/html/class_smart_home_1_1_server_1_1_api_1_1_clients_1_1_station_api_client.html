Detailed Description

While currently station entity hold in client body is used for enriched logging, it's main purpose is to allow configuration of the communication layer based on station-specific properties. Now configuration is static and applied to all stations, but in the future some station-specific configuration may be required.

The HttpClient is wrapped in Lazy<T> primarily to enhance testability. By deferring the initialization and configuration of the client, it is possible to instantiate the class in a unit testing context without providing a fully configured IHttpClientFactory during construction.
