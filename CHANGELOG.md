## Version 1.0.0

**Release Date:** 2026-04-16  
**License:** MIT  
**Contributors:**
- [Jakub Miodunka](https://github.com/JakubMiodunka "GitHub profile")

### Changes
- Initial release of the system, including both software and firmware.
- No custom hardware developed - development carried out on a generic NodeMCU board.
- Basic implementation of core mechanisms: communication between the central server and stations, station and feature registration,
heartbeat mechanism, and a server-controlled bistable switch on the station side as the sole supported feature.
